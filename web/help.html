File Index 使用說明

離線檔案索引工具：保存檔名、路徑、大小及修改時間，來源磁碟拔除後仍可搜尋。

使用說明

建立與搜尋索引

File details 的 Relative path 只顯示檔案相對於掃描來源的目錄，不包含檔名；檔案若直接位於來源根目錄，會顯示 (Storage root)。

  1. 在 Storage 按 Add storage，輸入來源目錄、名稱及備註，再按 Start scan。
  2. 掃描完成後，切換至 Search 輸入檔名或路徑關鍵字。多個詞以 AND 比對，也可選擇 Storage 或副檔名篩選。
  3. 初次開啟時結果為空；按 Search 執行查詢。空白關鍵字可列出符合篩選的全部索引。View files 可直接查看指定 Storage。
  4. 點選結果查看詳細資訊；Open folder 在支援的平台開啟來源目錄並選取檔案；Open File 使用作業系統的預設程式開啟檔案。兩者都要求來源已連接且檔案仍存在。

Filename / Relative Path 表頭依序切換檔名升冪、路徑加檔名升冪、檔名降冪、路徑加檔名降冪；Storage、Size、Modified 可切換升降冪。

維護 Storage

  • Rescan：直接掃描目前保存的來源位置並更新索引，不需再輸入路徑。取消或失敗時保留舊索引。
  • Relocate：磁碟代號或目錄位置改變時指定新位置；不搬移檔案、不重新掃描。
  • Delete：刪除選取的 Storage 與其檔案索引，不刪除來源檔案。資料庫會回收完整空白頁面；少量刪除可能不改變檔案大小。
  • Export CSV：匯出符合搜尋条件的全部結果或指定 Storage，以 UTF-8 BOM 輸出，不受當頁筆數限制。

備份與結束

Backup 可建立備份或還原。還原會完整取代目前資料庫，並先建立安全備份；舊備份可能包含已刪除的 Storage。

使用 Exit File Index 結束程式；正在掃描時可確認取消並離開。狀態由 Stopping server… 變為 Server stopped 後可關閉分頁。只關閉瀏覽器不會停止程式。拔除隨身碟前請先結束程式。

Exit File Index 在服務停止後會嘗試自動關閉目前分頁；若瀏覽器禁止自動關閉，會保留 Server stopped 提示，請手動關閉。其他分頁不受影響。

設定欄位說明

修改後按 Save settings 保存。路徑以程式所在資料夾為基準；macOS 為 FileIndex.app 旁，開發模式為專案根目錄。三個路徑必須是此目錄內的相對路徑，不能使用絕對路徑或跳到上層。

Database path
SQLite 索引資料庫位置，預設 data/fileindex.db。修改後重新啟動才切換資料庫，不會自動搬移原資料；若要保留索引，請先備份並妥善搬移或還原。
Backup path
備份存放目錄，預設 backup。保存後後續備份使用新目錄，舊備份不會自動搬移。
Export path
CSV 匯出目錄，預設 export。保存後後續匯出使用新目錄，既有匯出檔不會自動搬移。
Search page size
每頁搜尋筆數，範圍 1～1000，預設 100。影響後續搜尋，不限制 CSV 匯出的總筆數。
HTTP port
本機網頁服務的連接埠，範圍 0～65535；0 表示自動選擇可用連接埠。修改後重新啟動生效；指定的埠若被占用可能無法啟動。
Auto open browser
下次啟動時是否自動開啟預設瀏覽器。選 No 時需使用終端機提供的 Session URL；沒有主控台視窗的版本建議保持 Yes。
Date and time format
介面的日期與時間格式：System locale 使用系統格式；其他選項提供年/月/日或日/月/年順序，以及 12／24 小時制。保存後更新顯示，不改變資料庫中的時間紀錄。

Storage 欄位說明

Last scan root
上次成功掃描使用的來源目錄。
Current root
目前來源位置；Relocate 更新此欄位，Rescan 與 Open folder 使用此位置。
Filesystem
上次成功掃描取得的檔案系統，例如 NTFS、exFAT 或 APFS；可取得時另顯示識別資訊。舊索引可 Rescan 補齊，無法取得時顯示 Unavailable。
Capacity
上次掃描時，來源所在磁碟區的總容量，不是已索引檔案大小或剩餘空間。掃描子目錄也顯示所在磁碟區容量；Windows 配額可能影響回報值。無法取得時顯示 Unavailable。
Last scan
上次成功完成掃描的時間。Relocate 不更新此時間或上次掃描的磁碟資訊。
